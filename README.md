# STEP Assignment - Week 1

Five Java solutions for the Week 1 array and string problems.

## Package
`assigment_problems` (spelling retained from the assignment guide).

## Programs
1. `ExamHallSeatDuplicationChecker`
2. `TypingSpeedTestAccuracyChecker`
3. `TrafficSignalStreakAnalyzer`
4. `WarehouseInventoryBalancer`
5. `MovieReviewWordLengthProfiler`

Each class has its own `main` method and can be run independently. Compile from the project root:

```bash
javac -d out src/main/java/assigment_problems/*.java
java -cp out assigment_problems.ExamHallSeatDuplicationChecker
```

Replace the class name in the final command to run another program.
